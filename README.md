# Free Tools Hub

A collection of free online tools that run entirely in your browser. No signup, no downloads, no data uploads.

## Tools Included

- **Image Compressor** — Compress JPG, PNG, and WebP images without losing quality
- **QR Code Generator** — Create QR codes for links, text, and more
- **Word Counter** — Count words, characters, sentences, and paragraphs
- **Age Calculator** — Calculate your exact age in years, months, and days
- **Invoice Generator** — Create professional invoices and save as PDF
- **Password Generator** — Generate strong, secure random passwords

## Guides

Each tool comes with a detailed guide article to help you get the most out of it.

## Tech

- Pure HTML, CSS, and JavaScript
- Hosted on GitHub Pages
- 100% client-side — your data never leaves your device
